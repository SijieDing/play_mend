# Tools
Tools to get data from opensearch

## How to use
get_input_data.py - to get raw data from opensearch
get_baseline.py - to get baseline
get_anomalies.py - to extract anomalies

Put the file that will be used inside aiops_unite_pkg folder 
Mention metric config and date in the specified variables

## Usage
```python
python <file_name>.py
```
It will start a flask server. Run the specific endpoint mentioned in the file and you will get csv file
